One word for the whole internet: "feral". A tiny deterministic Python program that validates the word and writes it to the competition's output file — because the internet is unfiltered, untamed, and proud of it. Five letters, one beat: it makes you laugh, then you nod, because you have seen it with your own eyes.

## Run it

```sh
python3 main.py /output/entry.txt
```
